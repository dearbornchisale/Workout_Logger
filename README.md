🏋️ Workout Logger

A full-stack workout tracking application that allows users to manage workout sessions, record exercises, monitor strength progression and track their fitness journey over time.

Live Demo: https://workout-logger-gu7d.vercel.app

⸻

📖 About

Workout Logger is a personal fitness tracking application developed to provide users with a simple and organised way to manage their gym workouts.

The application allows authenticated users to create workout sessions, record exercises, track sets, repetitions and weights, and review their workout history.

This project was independently designed, developed and deployed as a practical application of full-stack software engineering concepts.

✨ Features

* User Authentication: Secure user authentication through Supabase.
* Workout Management: Create and manage individual workout sessions.
* Exercise Logging: Record exercises performed during workout sessions.
* Set Tracking: Record sets, repetitions and weights.
* Workout History: View previously recorded workout sessions.
* Workout Editing: Update existing workout records.
* Workout Deletion: Remove workout sessions when necessary.
* Responsive Design: Interface designed to work across different screen sizes.

⸻

🗄️ Database

The application uses PostgreSQL through Supabase to store and manage application data.

The database supports the application’s core functionality, including:

* User information
* Workout sessions
* Exercise records
* Workout sets

Supabase provides the backend infrastructure, authentication services and database integration.
